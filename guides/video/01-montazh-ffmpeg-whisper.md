# Монтаж рілса без програм монтажу: ffmpeg + Whisper + Pillow

Кейс: людина говорить у камеру 30-60 с, треба субтитри українською, анімовані вставки і CTA. Усе робить Claude Code скриптами, без Premiere і CapCut.

## Інструменти

- **ffmpeg**: static build з https://github.com/BtbN/FFmpeg-Builds/releases (Windows) або `winget install ffmpeg`. Якщо в тебе вже є Node-проєкт, бінарник лежить у npm-пакеті `ffmpeg-static`.
- **Розпізнавання мови** (обрати одне):
  - `whisper.cpp` (`whisper-cli.exe`) + модель `ggml-large-v3-turbo` (1.6 ГБ), добре знає українську;
  - `faster-whisper` у Python (`pip install faster-whisper`), torch не потрібен, працює на CPU. Див. [03-transkrybatsiya-yt-dlp-whisper.md](03-transkrybatsiya-yt-dlp-whisper.md).
- **Python + Pillow** для карток субтитрів і покадрових міні-анімацій.

## Пайплайн

1. Аудіо: `ffmpeg -i video.mp4 -ar 16000 -ac 1 audio.wav`
2. Whisper: `whisper-cli -m ggml-large-v3-turbo.bin -l uk -osrt -ojf audio.wav` (srt + json з пословними таймкодами).
3. Субтитри, простий варіант: ASS-файл (Montserrat ExtraBold, білий + акцентний колір, чорна обводка 7 px, по центру знизу MarginV 400, поп-анімація `\t(\fscx)`), шматки по 2-4 слова.
4. Рендер: `-filter_complex "...overlay...; subtitles=file.ass:fontsdir=fonts"` → `libx264 -crf 18`.

## Просунутий рівень: Pillow-оверлеї замість ASS

ASS виглядає «дешево». Краще так:

- **Картки субтитрів** генерує Pillow як PNG: жирний шрифт, ключове слово на кольоровій плашці (rounded rect), ледь помітна тінь (offset 6 px, blur 7, alpha ~115). Субтитри строго рівні, без нахилів і «дитячих» тіней.
- **Замість емоджі покадрові міні-анімації**, намальовані Pillow: 30 fps PNG-секвенція → ffmpeg `image2` demuxer → `tpad` (clone, утримати останній кадр) → `setpts` (зсув на стартовий час) → `overlay`. Приклади, що спрацювали: графік заявок, що падає (лінія малюється прогресивно), бюджет-бар, що тане 100%→12% зі зміною кольору, повзунки, що з'їжджають у неправильні позиції, спливаючі чіпи «✓ Нова заявка» ×3, CTA-кнопка з пульсацією (scale 1±2.2%, синус 1.6 с).
- **Панелі на всю ширину верху кадру** (~1000 px, y≈100-150), кожна під конкретну фразу.
- **Моушн:** `zoompan` повільні наїзди по фразах (1.0→1.08), rise-in субтитрів через y-вираз overlay, прогрес-бар зверху `overlay x='-1080+1080*t/DUR'`.
- **Звук:** `loudnorm I=-14` (стандарт Reels).
- Easing-функції в Python: ease_out cubic, ease_in_out, ease_out_back (overshoot).
- Один Python-скрипт генерує і всі PNG, і готовий рядок ffmpeg-команди → один рендер.

## Правила ритму (з правок замовника)

- 9 анімацій на 40 с забагато. Залишили 5, кожна розтягнута на всю свою фразу (~2-2.6 с замість 1.2-1.5 с).
- Моушн-елемент живе стільки, скільки триває фраза, і анімується ~70-80% цього часу.
- CTA: шрифт 46, ширина плашки ≤1000 px, інакше впирається в краї кадру.

## Нюанси

- Whisper інколи бреше у словах («проаналізуємо» → «пронорізуємо»): транскрипт вичитувати.
- Таймкоди Whisper квантовані по сегментах, уточнювати через `silencedetect`.
- Однакові на вигляд дублі перевіряти PSNR-порівнянням: два файли можуть бути одним дублем у двох експортах.
- `curl -C -` (докачування) на gyan.dev ламає zip, качати одним шматком.
